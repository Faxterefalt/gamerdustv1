# apps/web

Interfaz React de Gamerdust.

Hoy el frontend se sirve con Inertia desde Laravel, por lo que su código vive en
[`apps/api/resources/js`](../api/resources/js), organizado por funcionalidades
(`features/`, `layouts/`, `shared/`, `app/`). Esta carpeta queda reservada para
cuando la interfaz se separe como SPA independiente.
