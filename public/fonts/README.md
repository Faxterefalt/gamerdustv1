# Fuentes

Autoalojadas para no depender de Google Fonts en tiempo de ejecución. Todas con licencia [SIL Open Font License 1.1](https://openfontlicense.org).

| Familia | Uso | Archivos |
|---|---|---|
| Atkinson Hyperlegible Next (Braille Institute) | Texto de lectura e interfaz (400 y 700, variable) | `atkinson-hyperlegible-next-variable-*.woff2` |
| Courier Prime (Quote-Unquote Apps) | Solo la hoja del editor de guion | `courier-prime-*.woff2` |
| Pixelify Sans (Stefie Justprince) | Acento: logotipo, titulares cortos, cifras tipo HUD | `pixelify-sans-700-*.woff2` |

Subconjuntos `latin` y `latin-ext` (español, inglés y tildes). Las reglas `@font-face` están en `resources/css/fonts.css`.
